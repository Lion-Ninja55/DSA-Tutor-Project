# 📚 DSA Tutor Project

A beginner‑friendly Python project designed to help users learn and understand fundamental Data Structures and Algorithms (DSA). This interactive program teaches concepts through explanations and practical examples, making it ideal for students who are just starting their DSA journey.

The project is split into two files: a main program that handles user interaction, and a module file that contains all algorithm functions. This keeps the project clean, organized, and easy to expand.

---

## 🚀 Features
- Interactive text‑based learning system  
- Beginner‑friendly explanations of DSA concepts  
- Practical demonstrations of algorithms  
- Fully implemented examples:
  - Arrays  
  - Minimum Value Finder  
  - Binary Search  
  - Bubble Sort  
  - Quick Sort  
  - Selection Sort  
- Placeholder lessons (not implemented yet):
  - Insertion Sort  
  - Radix Sort  
  - Merge Sort  
  - Counting Sort  

These placeholder lessons currently print “This lesson is under construction” inside the module file.

## 🧠 How It Works

### main.py
This file is the entry point of the program. It:
- Displays the DSA menu  
- Explains each topic  
- Handles user input  
- Calls the matching function from the module  
- Controls the flow of the learning system  

It acts as the “teacher” of the program.

### secondary.py
This file is the module that contains all the algorithm functions.  
Each function:
- Builds a list or array  
- Runs the chosen algorithm  
- Prints the result  
- Demonstrates how the algorithm works  

Fully implemented functions:
- ArraysLesson()  
- MinValFind()  
- BinarySearcher()  
- BubbleSorter()  
- QuickSorter()  
- SelectionSorter()  

Placeholder functions (not implemented yet):
- InsertionSorter()  
- RadixSorter()  
- MergeSorter()  
- CountingSorter()  

These currently only print “This lesson is under construction.”
